# 私有内容与公开代码边界

这个仓库公开网站程序、通用产品权益能力，以及两个已经对外发布的案例快照。生产数据和未公开业务内容必须保留在公开 Git 历史之外。

## 可以公开

- 前台、后台和 API 源代码
- 通用数据库结构与面向全新安装的基础迁移
- 不含真实凭据的环境变量模板
- 已公开案例的精简标题、摘要、正文节选和封面
- 通用商品、套餐、订单、优惠码和权益逻辑

## 必须留在私有环境

- 未公开或收费的正文、附件、图片和内容清单
- 用户、订单、支付回调与访问日志
- 下载地址、交付链接、授权文件和数据库备份
- 服务器地址、部署脚本、证书、私钥和第三方服务密钥
- 内部运营说明、客服记录和供应商资料

推荐将这类数据保存在生产数据库、对象存储、外部内容服务或独立私有仓库中。不要把私有内容先提交再删除；Git 历史仍会保留旧版本。

公开 baseline 只用于全新安装；已有数据库必须保留自己的 migration 历史，不能直接改用该 baseline。

## 发布前检查

```bash
npm run release:check
git status --short
git log --oneline --decorate -10
```

自动扫描只能覆盖明确的路径和高置信密钥。推送前仍需人工检查提交差异、完整提交历史、图片元数据和演示数据，确认其中没有真实用户、订单、内部 URL 或未公开内容。
